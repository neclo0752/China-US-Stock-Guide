# 总结下

## 盈透（Interactive Brokers）

盈透是 4 家能开的美国券商里综合能力最强的，有条件优先上这个。

**优点**

1. **出入金简单，损耗低**

   盈透可以像香港券商一样使用 FPS 和 eDDA 来进行入金，全程 0 损，速度贼快。在出金上，每月前两笔免费，常规情况下够用了。

2. **汇率好**

   盈透的汇率是接近市场中间价的，唯一的损耗就是每笔 2 美元的手续费。

   举个例子，10W 美元换人民币(以2026.10.20市场汇率计)：
   - 盈透：扣掉手续费可以换 668,987 人民币
   - 汇丰：只能换 663,882 人民币

   盈透比汇丰整整多了 5000 多人民币。有 pulse 信用卡的朋友，可以优先在盈透换完再入汇丰。

3. **可以买全球市场**
   - 担心遗产税问题，可以买入爱尔兰 ETF，如 CDNX、SPYL 这些，这些资产不计入 6W 美元额度。
   - 想梭哈原汁原味的海力士、三星，可以开通韩股交易权限。

4. **融资利率低**

   几家里面，盈透的融资利率最低，只有 5.38%，融的越多，利率越低。对比之下嘉信 10%+。

**缺点**

1. **开户难度高**

   海外地址证明卡了很多人。个人不建议为了开盈透找中介搞假地址，给日后埋雷，出问题时处理起来比较麻烦。

2. **APP 体验一般**

   多数页面还是古老的 H5 页面，加载慢，体验差。为什么不用原生框架搞，尤其是 AI 带来 coding 效率极大提升下。赚这么多钱，也该优化下基础设施吧。

3. **手续费不低**

   交易手续费整体比另外三家都贵。盈透也有个 Lite 版（免佣）的，国内用不了。

## 嘉信（Charles Schwab）

**优点**

1. **开户门槛低**

   全套国内资料就能申请，不需要为地址证明的问题发愁。

2. **交易成本低**

   普通个股交易 0 佣金 0 平台费，期权 0.65 美元一张。一度很多人问，嘉信靠啥赚钱？

3. **规模大**

   作为全美排名前三的大券商，不用担心不合规跑路的问题。耳熟能详的 SCHD、SCHG、SCHV 都是出自嘉信。

**缺点**

1. **出入金流程复杂，折损高**

   相比盈透，出入金流程略复杂。有时为了控制折损还需借助 Wise，算来算去，对于新手还是有点门槛。出入金到账久，以天来计，远没盈透的出入金快。

2. **APP 难用**

   APP 出了名的难用，每年赚这么多钱为啥不优化一些 APP。原版 Schwab 只有英文版，thinkorswim 有中文版，但依旧不好用。  
   中文客服支持弱。

3. **支持的市场太少**

   主要还是做美股，其他的市场要么只能电话下单，要么直接不支持。爱尔兰 ETF 嘉信也不支持。

4. **融资利率高**

    10%+ 的融资利率，即使再好的机会也得算一下是否划算。几家券商里它是最高的。
