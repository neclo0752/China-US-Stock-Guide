## 一.开通券商账户
投资美股常见的方式有三种：香港券商，美国券商，加密平台  
三者都能操作美股，但是区别又比较大：

| 对比维度 | 香港券商 | 美国券商 | 加密平台 | 
|---------|---------------------|--------------------|-----------|
| CRS | 参与 | 不参与 | 不参与 |
| 大陆用户是否可开 | 可以（富途不行） | 可以（IB需要海外地址证明） | 可以 |
| 出入金复杂度 | 简单 | 复杂 | 简单 |
| 出入金时效 | 快 | 慢 | 快 |
| 联系人工复杂度 | 简单 | 复杂 | 复杂 |
| 交易品类丰富度 | 中 | 高 | 低 |
| 交易时间 | 常规时间 | 常规时间 | 7*24小时 |
| 是否支持港股交易 | 支持 | 不支持（仅IB支持） | 部分平台支持少数标的 |
| 是否支持港股打新 | 是 | 否 | 否 |
| 是否支持热门A股做空 | 否 | 否 | 是 |
| 投资者保障 | SIPC保障（50W美元） | SIPC保障（50W美元） | 不受SIPC/ICF覆盖，依赖发行方托管安排 |
| 持有的是股权还是凭证 | 股权 | 股权 | 凭证 |
| APP体验 | 非常好 | 差 | 友好 |

### 怎么选？
如果你专注于港股交易（如智谱、minmax、腾讯、美团）、港股打新，低频美股交易，追求极简的出入金流程和快时效，快速的人工响应，首选香港券商。💡 **快速通道**：[香港本土券商对比](./1.券商/香港本土券商对比.md)  

如果你专注于美股交易，对CRS不能容忍，能接受复杂出入金流程复杂、成本高和慢时效，且不交易港股，首选美国券商。 💡 **快速通道**：[美国本土券商对比](./1.券商/美国本土券商对比.md)     

如果你没有港卡美卡，追求低门槛开户，24小时可交易，做空热门A股（如宇树、长鑫），首选加密平台。


## 二.开通银行账户
经过第一步，你就已经拥有一个可操作的美股交易平台了。

注意国内的银行卡是不能直接给这些平台入金的。

此时，你需要开通一个境外的银行账号（注意：加密平台比较特殊，后面单独讲），常见的有香港银行卡、美国银行卡、新加坡银行卡、英国银行卡等其他卡，以及可用于资金中转的第三方金融机构wise。  

我将以上银行卡归位三类进行对比：
| 对比维度 | 香港银行卡 | 美国银行卡 | 第三方平台或银行 | 
|---------|---------------------|--------------------|-----------|
| CRS | 参与 | 不参与 | 参与 |
| 大陆用户是否可开 | 可以（多数门槛较低） | 可以（多数门槛较高） | 可以 |
| 开户复杂度 | 简单 | 复杂 | 一般 |
| 是否可支持出入金 香港券商| 支持 | 支持（手续费及时效差） | 不支持（ifast可） |
| 是否可支持出入金美国券商 | 支持（手续费及时效差） | 支持 | 支持 |
| 持卡成本 | 低 | 高 | 低 |
| 联系人工复杂度 | 简单 | 复杂 | 复杂 |
| 投资者保障 | DPS保障（80W港币） | FDIC保障（25W美元） | wise（存在其他银行） <br>ifast（FSCS保障8.5W英镑） |


### 怎么选？

我认为**香港卡**必须有，它直接决定我们跨境资金的安全性和便利性，出问题极易追溯核查。但是这么几十家香港银行，到底怎么选？💡 **快速通道**：[香港本土银行对比](./2.银行/香港本土银行对比.md)  

---


**美国银行卡**最大的优势就是不参与CRS，最大的劣势就是开户门槛相对较高。美国银行与美国券商之间通过ACH出入金（类似国内的银证转账）非常方便。  
但是大陆用户能开的也有很多家，优缺点如何？ 💡 **快速通道**：[美国本土银行对比](./2.银行/美国本土银行对比.md)     

---

如果你既不想办香港卡又不想办美国卡，又想投资美股出入金，那么还有一个折中选择：**第三方平台或银行**。  
对，我这里说的就是**Wise** 和 **iFast**，这哥俩是为数不多还向大陆用户开放申请的。
在我看来，这哥俩的核心用途就两点：

---

**① 暂时没有港卡或美卡，但是又想入金**

```
内地购汇  →  Wise / iFast  →  美国券商
```

港卡办不下来或者懒得折腾的，这条路能直接绕过去。

---

**② 有港卡，担心CRS标记，想中转**

```
内地购汇  →  香港银行卡  →  Wise / iFast  →  美国券商
```


关于这哥俩怎么用可以参考：[第三方机构或银行](./2.银行/第三方平台或银行.md)







## 三.资金进出

经过第一步和第二步，你拥有了合规的**券商账户**和**银行卡**。  
接下来我们开始聊资金怎么转进去和提出来(也就是入金和出金)：

### 入金（资金由银行->券商）

如果你在国内买A股，入金方式很简单，银行和证券绑定即可，从券商APP可以直接发起银证转账即可。 

但是要投资美股，入金到境外券商，就涉及购汇、跨境转账、入金券商等一系列流程。  
你需要关注汇率折损、手续费折损、到账速度、链路稳定不稳定、有没有CRS等一些列问题。  
我总结了其中的5种入金方法，可以参考：[美股入金5种方案](./3.出入金/入金.md)     




### 出金（资金由券商->银行）
同样，出金我们也依然需要考虑很多因素，手续费、汇率折损、到账速度、会不会遇到风控，有没有CRS等多个问题。  

我也总结了5种方案可供参考：[美股出金5种方案](./3.出入金/出金.md)     




## 四.税务问题
从很多朋友给我的私信里看，大家过于焦虑 CRS 问题。

关于 CRS，我认为要搞明白以下两点，才能缓解你的焦虑：

1. **搞清楚 CRS 的参与范围与机制**：哪些银行、券商会参与，哪些不参与，参与的机构上报哪些信息，以及怎么上报。
2. **税务核查的逻辑是信息一致性**：只有存在巨额的反差，才会引起关注。

我整理了一份 CRS 文档，可以参考：[刨根问底 CRS](./4.税务/crs.md)
